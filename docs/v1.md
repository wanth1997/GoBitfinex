# Bitfinex V1 API Reference (Legacy)

```go
import "github.com/wanth1997/GoBitfinex/v1"
```

Package `bitfinex` (`v1`) is frozen for legacy compatibility; new features belong in `v2/rest` or `v2/websocket`. All V1 REST service methods use the `V1` prefix.

For full struct definitions, constants, and doc comments, run:

```bash
go doc -all github.com/wanth1997/GoBitfinex/v1
go doc github.com/wanth1997/GoBitfinex/v1.OrderService
```

## Client Initialization

```go
client := bitfinex.NewClient()
authClient := bitfinex.NewClient().Auth(apiKey, apiSecret)
```

## REST Services (`*Client`)

| Field | Type | Methods |
|---|---|---|
| `Account` | `*AccountService` | `V1Info() (AccountInfo, error)`, `V1KeyPermission() (Permissions, error)`, `V1Summary() (Summary, error)` |
| `Balances` | `*BalancesService` | `V1All() ([]WalletBalance, error)` |
| `Credits` | `*CreditsService` | `V1All() ([]Credit, error)` |
| `Deposit` | `*DepositService` | `V1New(method, walletName string, renew int) (DepositResponse, error)` |
| `History` | `*HistoryService` | `V1Balance(currency, wallet string, since, until time.Time, limit int) ([]Balance, error)`, `V1Movements(currency, method string, since, until time.Time, limit int) ([]Movement, error)`, `V1Trades(pair string, since, until time.Time, limit int, reverse bool) ([]PastTrade, error)` |
| `Lendbook` | `*LendbookService` | `V1Get(currency string, limitBids, limitAsks int) (Lendbook, error)`, `V1Lends(currency string) ([]Lends, error)` |
| `MarginFunding` | `*MarginFundingService` | `V1NewLend(currency string, amount, rate float64, period int) (MarginOffer, error)`, `V1NewLoan(currency string, amount, rate float64, period int) (MarginOffer, error)`, `V1Cancel(offerId int64) (MarginOffer, error)`, `V1Status(offerId int64) (MarginOffer, error)`, `V1Credits() ([]ActiveOffer, error)`, `V1Offers() ([]ActiveOffer, error)` |
| `MarginInfo` | `*MarginInfoService` | `V1All() ([]MarginInfo, error)` |
| `Offers` | `*OffersService` | `V1New(currency string, amount, rate float64, period int64, direction string) (Offer, error)`, `V1Cancel(offerId int64) (Offer, error)`, `V1Status(offerId int64) (Offer, error)` |
| `OrderBook` | `*OrderBookService` | `V1Get(pair string, limitBids, limitAsks int, noGroup bool) (OrderBook, error)` |
| `Orders` | `*OrderService` | `V1All() ([]Order, error)`, `V1Create(symbol string, amount, price float64, orderType string) (*Order, error)`, `V1CreateMulti(orders []SubmitOrder) (MultipleOrderResponse, error)`, `V1Cancel(orderID int64) error`, `V1CancelAll() error`, `V1CancelMulti(orderIDS []int64) (string, error)`, `V1Replace(orderID int64, useRemaining bool, newOrder SubmitOrder) (Order, error)`, `V1Status(orderID int64) (Order, error)` |
| `Pairs` | `*PairsService` | `V1All() ([]string, error)`, `V1AllDetailed() ([]Pair, error)` |
| `Positions` | `*PositionsService` | `V1All() ([]Position, error)`, `V1Claim(positionId int, amount string) (Position, error)` |
| `Stats` | `*StatsService` | `V1All(pair string, period, volume string) ([]Stats, error)` |
| `Ticker` | `*TickerService` | `V1Get(pair string) (Tick, error)` |
| `Trades` | `*TradesService` | `V1All(pair string, timestamp time.Time, limitTrades int) ([]Trade, error)` |
| `Wallet` | `*WalletService` | `V1Transfer(amount float64, currency, from, to string) ([]TransferStatus, error)`, `V1WithdrawCrypto(amount float64, currency, wallet, destinationAddress string) ([]WithdrawStatus, error)`, `V1WithdrawWire(...) ([]WithdrawStatus, error)` |

## WebSocket Service (`*Client.WebSocket`)

`WebSocketService` exposes:

- `NewWebSocketService(c *Client) *WebSocketService`
- `Connect() error`
- `ConnectPrivate(ch chan TermData)`
- `AddSubscribe(channel string, pair string, c chan []float64)`
- `Subscribe() error`
- `ClearSubscriptions()`
- `Close()`
